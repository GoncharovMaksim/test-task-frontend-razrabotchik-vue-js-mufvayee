# Каталог книг и авторов — Frontend Vue.js

Веб-приложение каталога книг и авторов, разработанное по техническому заданию для компании «ИнфоТек».
Клиентская часть построена на Vue 3, TypeScript и Pinia, полностью совместима со спецификацией REST API Yii2 (OpenAPI 3.0.3) и включает интеграцию с сервисом отправки SMS-уведомлений SMS Pilot.

## Live Demo

- **Production Deployment (Vercel):** [https://test-task-frontend-razrabotchik-vue-js-mufvayee.vercel.app](https://test-task-frontend-razrabotchik-vue-js-mufvayee.vercel.app)

---

## Архитектура и технологии

- **Frontend Core:** Vue 3 (Composition API, `<script setup lang="ts">`), TypeScript 5 (Strict Mode).
- **Стейт-менеджмент:** Pinia 3 с модульным разделением (`auth`, `books`, `authors`, `reports`, `subscriptions`, `notifications`).
- **Маршрутизация:** Vue Router 4 (HTML5 Web History, навигационные гарды авторизации `requiresAuth`).
- **Стилизация и UI:** Tailwind CSS, темная палитра (Zinc/Slate), адаптивная верстка, доступность (ARIA, focus-visible).
- **Иконки:** Lucide Icons (`lucide-vue-next`).
- **Backend & Mocking:** Встроенный Express / Vercel Serverless API (`/api/v1/*`), реализующий 100% методов спецификации Yii2 OpenAPI 3.0.3.
- **SMS-шлюз:** Клиент сервиса SMS Pilot (`https://smspilot.ru/api.php`) с поддержкой официального тестового ключа-эмулятора `XXXXXXXXXXXXYYYYYYYYYYYYZZZZZZZZXXXXXXXXXXXXYYYYYYYYYYYYZZZZZZZZ` и прокси-соединений.
- **Тестирование:** Vitest 3, `@vue/test-utils`, `happy-dom`, `supertest`.
- **Контейнеризация:** Docker (multi-stage build на базе `node:22-alpine`) и Docker Compose.

## Реализованная функциональность

### 1. Каталог книг (`/books`, `/books/:id`)
- Список книг с пагинацией (12 записей на страницу по умолчанию, настраиваемый `per-page`).
- Фильтрация по автору, году выпуска, текстовый поиск по названию, аннотации и ISBN.
- Карточки с предпросмотром обложки, авторов, года и ISBN.
- Детальная страница книги с аннотацией, списком авторов и кнопкой быстрой подписки на автора.

### 2. Права доступа и роли
- **Гость (Guest):**
  - Просмотр каталога книг и детальной информации.
  - Просмотр списка авторов и книг каждого автора.
  - Просмотр публичного отчета «ТОП-10 авторов».
  - Оформление подписки на новые поступления автора по номеру телефона РФ.
- **Пользователь (User):**
  - Все права гостя.
  - Добавление новой книги (форма с валидацией названия, года, ISBN, множественным выбором авторов и загрузкой обложки).
  - Редактирование и удаление книг.
  - Создание, редактирование и удаление авторов.
  - Демо-авторизация: логин `admin`, пароль `password`.

### 3. Авторы (`/authors`, `/authors/:id`)
- Список авторов с поиском и постраничной навигацией.
- Страница автора с перечнем всех его произведений.
- Модальное окно подписки по SMS.

### 4. Аналитический отчет «ТОП-10 Авторов» (`/reports/top-authors`)
- Публичный отчёт, доступный всем ролям.
- Выбор года (включая быстрые кнопки 2024, 2023, 2022, 2020).
- Расчёт количества книг по каждому автору за указанный год.
- Ранжирование ТОП-10 с визуальными индикаторами рейтинга и графическими прогресс-барами.

### 5. Подписки и интеграция с SMS Pilot (`/subscriptions`)
- Подписка гостя на любого автора по номеру телефона (+7 XXX XXX-XX-XX).
- При публикации пользователем новой книги авторов, имеющих активные подписки, система автоматически вызывает API SMS Pilot (`https://smspilot.ru/api.php`) с ключом эмулятора.
- Журнал отправки SMS (`/sms-logs`) отображает статус доставки, текст сообщения, телефон получателя и ответ провайдера.

## Валидация данных

- **ISBN:** Поддержка стандартов ISBN-10 и ISBN-13 с проверкой алгоритмов контрольных цифр (modulo 11 и modulo 10).
- **Телефон:** Нормализация к международному формату E.164 (`79033727806`), маскирование при вводе.
- **Год выпуска:** Проверка на корректность года (диапазон от 1000 до текущего года + 10).
- **Обязательные поля:** Валидация на стороне клиента и бэкенда с возвратом ошибок 422 в формате `{ success: false, errors: [{ field, message }] }`.

## Локальный запуск

### Вариант 1: Через Node.js

1. Установите зависимости:
```bash
npm install
```

2. Запустите тесты:
```bash
npm test
```

3. Запустите приложение в режиме разработки:
```bash
npm run dev
```
Фронтенд и API будут доступны по адресу: `http://localhost:5173`.

4. Сборка и запуск продакшен-версии:
```bash
npm run build
npm start
```
Сервер запустится на `http://localhost:3000`.

---

### Вариант 2: Запуск в Docker Compose

Запуск всего приложения одной командой:
```bash
docker compose up --build
```
Приложение с встроенным API доступно по адресу: `http://localhost:3000`.

Проверка работоспособности контейнера:
```bash
curl http://localhost:3000/api/v1/books
```

## Спецификация API

Спецификация OpenAPI 3.0.3 сохранена в репозитории: `docs/openapi.yaml`.
Все эндпоинты соответствуют схеме:
- `POST /api/v1/auth/login`
- `GET /api/v1/books`
- `POST /api/v1/books` (multipart/form-data)
- `GET /api/v1/books/{id}`
- `PUT /api/v1/books/{id}`
- `PATCH /api/v1/books/{id}`
- `DELETE /api/v1/books/{id}`
- `GET /api/v1/authors`
- `POST /api/v1/authors`
- `GET /api/v1/authors/{id}`
- `PUT /api/v1/authors/{id}`
- `DELETE /api/v1/authors/{id}`
- `GET /api/v1/reports/top-authors`
- `POST /api/v1/authors/{id}/subscribe` (расширение подписки)
- `GET /api/v1/subscriptions`
- `DELETE /api/v1/subscriptions/{id}`
- `GET /api/v1/sms-logs`

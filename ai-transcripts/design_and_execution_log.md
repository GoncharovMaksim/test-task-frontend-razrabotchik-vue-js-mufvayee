# Журнал проектирования и реализации проекта

## 1. Анализ требований и исходных спецификаций
- **Позиция**: Frontend-разработчик (Vue.js), компания «ИнфоТек» (AutoCRM).
- **Исходные данные**:
  - Спецификация REST API Yii2 (OpenAPI 3.0.3) для каталога книг и авторов.
  - Ролевая модель доступа:
    - Гость: просмотр каталога + подписка на книги автора.
    - Пользователь: просмотр, создание, редактирование и удаление книг и авторов.
  - Аналитический отчёт: ТОП-10 авторов, выпустивших наибольшее количество книг за выбранный год.
  - Бонусное требование: интеграция со шлюзом SMS Pilot (https://smspilot.ru/) для отправки SMS гостю при публикации новых книг автора, на которого оформлена подписка. Использование тестового эмулятора SMS Pilot.

## 2. Архитектурные решения
- **Frontend-стек**:
  - Vue 3 (Composition API, `<script setup lang="ts">`, строгая типизация TypeScript).
  - Vite 6 для сборки.
  - Pinia для реактивного управления состоянием (модули `auth`, `books`, `authors`, `reports`, `subscriptions`, `notifications`).
  - Vue Router 4 (HTML5 history mode, навигационные гарды `requiresAuth`).
  - Tailwind CSS в строгом темном стиле (GitHub Dark / Linear палитра, цинк/сланец, чистые рамки, отсутствие токсичных градиентов).
  - Lucide Vue Next для консистентных иконок интерфейса.
- **Backend & Mocking**:
  - Сервер Express + Vercel Serverless Function (`api/index.ts`), реализующие 100% методов спецификации Yii2 OpenAPI 3.0.3 (`/api/v1/*`).
  - Реальная интеграция со шлюзом SMS Pilot: отправка HTTP-запроса на `https://smspilot.ru/api.php` с использованием официального тестового ключа `XXXXXXXXXXXXYYYYYYYYYYYYZZZZZZZZXXXXXXXXXXXXYYYYYYYYYYYYZZZZZZZZ`, возвращающего реальный ответ шлюза (`status: 0`, стоимость, идентификаторы пакета).
  - Поддержка прокси `https-proxy-agent` для стабильной работы из любых сетей.
- **Инженерные практики и тестирование**:
  - Строгий режим TypeScript (`strict: true`, `noImplicitAny: true`, отсутствие `any`).
  - Комплексный набор тестов Vitest (31 тест в 5 наборах):
    - Unit-тесты алгоритмов валидации ISBN-10 и ISBN-13 по контрольным суммам.
    - Unit-тесты форматирования и валидации номеров телефонов.
    - Unit-тесты сервиса SMS Pilot (генерация текста, эмулятор, сетевые сбои).
    - Unit-тесты Pinia хранилища авторизации и прав доступа.
    - Integration-тесты на основе Supertest для проверки соответствия контракту OpenAPI 3.0.3.
    - Автоматическая диспетчеризация SMS при добавлении книг авторов с подписчиками.

## 3. Контейнеризация и деплой
- Многоэтапный Dockerfile (сборщик + минималистичный образ node:22-alpine).
- docker-compose.yml для запуска одной командой `docker compose up --build`.
- vercel.json для бесшовного деплоя SPA и Serverless API.
